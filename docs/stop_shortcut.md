# 停止当前任务快捷键

在运行申诉工具的 Windows 桌面中按 **Ctrl + Alt + F10**，请求停止当前运行任务。
这是 Windows 全局快捷键，申诉工具最小化、Chrome/Firefox 在前台时也可以接收。
使用 RDP 时需把按键发送到运行工具的远程桌面；本地日志网页不提供远程按键转发。

适用负向申诉、复议、售后申诉及流水线运行。触发后取消流水线后续阶段，走与现有停止按钮相同的安全停止路径。
已发出的提交需要先完成结果确认；不能用快捷键撤回平台已经收到的提交。等待桌面恢复时也能响应停止。
没有运行任务时不执行取消动作，也不弹出对话框。

程序底部显示快捷键注册状态；“帮助 → 停止当前任务”也可执行同一操作。
如果该组合被其他程序占用，底部和日志会明确提示未启用，仍可使用停止按钮或菜单。
退出 GUI 时释放快捷键。按住不放不会连续触发。
