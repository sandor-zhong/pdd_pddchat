# 鼠标坐标诊断日志

运行窗口和远程日志搜索“鼠标诊断”。负向申诉、复议、售后申诉会把该前缀的子进程日志转发到GUI及远程日志。

主要阶段：

- `viewport_changed`：每个页面首次定位及尺寸/DPI/窗口位置变化时输出，包含变化前后的参数、浏览器可视尺寸、screen尺寸、缩放、窗口位置及Windows窗口状态。普通移动不会反复输出同一几何状态。
- `locator_target`：定位器点击/悬停前的元素框、元素内偏移、页面CSS目标及调用位置。不记录元素文本和输入值。
- `chat_scroll_target`：每次聊天截图滚动前记录订单号、页码、容器框、可视交集、安全目标点、滚动位置及容器类型（页面或内部面板）。
- `target_out_of_view`：越界发生时的精确CSS目标、实际可视宽高、DPR、Windows窗口/客户区/显示器范围、最大化状态、前台窗口、桌面状态、代码文件及行号。
- `analysis_error`：分析失败后的订单号、错误类型和实际异常调用栈，便于与同进程前面的定位记录关联。
- `locator_remeasure`：点击发送前布局变化或短暂遮挡后有限次数重新定位，不重放已送出的点击。
- `locator_obscured`：遮挡元素的标签、类名和位置，不记录元素文字。
- `chat_target_unavailable`：多次取点仍不可见时记录聊天与视口的几何信息。

每条记录含时间、进程号和店铺；本机窗口API字段读取失败时尽量保留已收集字段。单条内容有长度上限。
页面只记录URL路径，剔除查询参数和片段；调用栈只保留文件名/行号/函数名，不记录源代码、变量、聊天正文或凭证。
`target_out_of_view` 和 `analysis_error` 在远程日志中标为ERROR。

比较方法：先找订单对应的`analysis_error`，按进程号找到前面的`target_out_of_view`和`chat_scroll_target`；比较容器中心与可视交集，以及是否有`viewport_changed`。由此区分容器中心本来就不可见、取点后窗口尺寸改变或其他调用直接传入越界坐标。
